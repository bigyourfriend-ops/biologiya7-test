# Авторлық білім беру ресурсы

Бейімделген тест: тест → жеке қайталау жоспары → қайта тексеру. Бірнеше пән мен сыныпқа арналған.
Деректер Supabase-те (`avtorlyq-resurs` жобасы) сақталады.

- `index.html` — мұғалім кабинеті (email мен құпия сөз арқылы кіру): пәндер, сыныптар, сұрақтар банкі, нәтижелер, талдау, Excel
- `test.html?s=<пән>` — оқушыға арналған тест (`&m=simple` — қарапайым тест, `#jury` — жюри сыныбы таңдалады)
- `qr.html?s=<пән>` — тестті бастау: QR кодтар
- `test-7a.html`, `test-7b.html` — бұрынғы сілтемелер (Биология 7-ге бағыттайды)
- `lib/config.js` — Supabase мекенжайы және жария кілт; `lib/supabase.js` — supabase-js (MIT)

Оқушылар тіркелмейді: нәтиже тест соңында Supabase-ке өзі жіберіледі. Нәтижелерді тек пәннің мұғалімі көреді.
