# Биология 7 · Тест және мұғалім кабинеті

7-сынып биология оқулығына негізделген бейімделген тест: тест → жеке қайталау жоспары → қайта тексеру.

- `index.html` — тестті бастау беті: 7 «А» және 7 «Б» тесттерінің QR кодтары
- `test-7a.html` — қателермен жұмыс бар тест (эксперимент сыныбы)
- `test-7b.html` — қарапайым тест, тек нәтиже (бақылау сыныбы)
- `kabinet.html` — мұғалім кабинеті: нәтиже кодтарын қосу, талдау, Excel

Нәтижелер мұғалімнің браузерінде сақталады; кабинетті бір компьютерде, бір браузерде ашыңыз.

QR генераторы: [qrcode-generator](https://github.com/kazuhikoarase/qrcode-generator) (MIT, © Kazuhiko Arase).
